# Task 09: UI результатов (study/results.html)

**Type:** Code Modification

## Goal

Обновить экран результатов: добавить таблицу ошибок с ответом пользователя, обновить кнопки навигации, улучшить поощрительные сообщения.

## What to Do

- **Обновить `study/results.html`**:
  - **Summary** — оставить как есть (Total Words, Correct, Incorrect, Score)
  - **Поощрительные сообщения** — оставить (≥80%, ≥50%, <50%)
  - **Таблица ошибок** — переработать секцию "Detailed Results":
    - Показывать **только неправильные ответы** (из модели `incorrectResults`)
    - Колонки: #, Слово (вопрос), Правильный ответ, Ваш ответ, Направление
    - Если `incorrectResults` пуст → "Поздравляем! Все ответы правильные!" (вместо таблицы)
    - Оставить также полную таблицу всех результатов (свернуть по умолчанию, раскрыть по клику "Показать все результаты")
  - **Кнопки навигации** — обновить:
    - "Пройти заново" → `POST /study/start` с теми же setIds (или `href="/study"`)
    - "Выбрать другие наборы" → `href="/study"`
    - "На главную" → `href="/sets"`
    - Убрать "Back to Cards"
